# Shivuu Special ❤️

A beautiful, romantic interactive webpage created with love for someone special.

## Features ✨

- 💫 **Smooth Animations** - Pulsing text, fade-in effects, and elegant transitions
- 🎯 **Interactive Buttons** - "Yes" and "No" buttons with fun responses
- 🎵 **Background Music** - Romantic music that plays on interaction
- 💝 **Falling Hearts Particle Effect** - Continuous hearts falling with swaying motion
- 🌈 **Gorgeous Gradient Styling** - Beautiful pink gradients with hover effects
- 📱 **Mobile Responsive Design** - Works perfectly on all devices
- 🎊 **Celebration Effects** - Confetti and intense heart rain on "Yes"

## How to Use

1. Open `index.html` in your browser
2. Click anywhere to start the background music
3. Click the **YES** button for a celebration! 🎉
4. Try the **NO** button for a playful surprise 😄
